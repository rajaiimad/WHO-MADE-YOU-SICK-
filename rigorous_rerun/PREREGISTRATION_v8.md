# Pre-registration v8 — a fresh confirmation lock-box (lock-box 2)
Written 2026-10-07, before any lock-box-2 cohort was generated or scored.

## Why
The raw-channel interaction HGB was added after the original lock-box (seeds 20000-20119) had
already been scored for every other model (round-3 review, reviewer B). Its lock-box comparison
with the MPNN is therefore not a confirmation on untouched data. This stage repeats the comparison
once on 120 fresh cohorts.

## Corpus
Lock-box 2: 120 cohorts, seeds 80000-80119 (disjoint from every earlier corpus, asserted),
generated by the v2 generator (stage3.generate with the v2 gain, which reproduces v2 exactly).
Scored once.

## Models (no changes, no re-tuning)
MPNN, raw-channel interaction HGB, excess-only interaction HGB, GAT, rule, prototype (original MLP).
Each is trained once per seed (5 seeds, 45/15 cohort split) on the v2 main development corpus with
its modal nested-CV configuration (the configuration used for Table V).

## Primary comparisons (paired cohort bootstrap, B = 1000)
1. Unsafe target: PR-AUC difference MPNN - raw-channel HGB.
2. Attacker-induced target: the same difference.
Reported whatever the sign. A difference is called significant only if its 95% CI excludes 0.
Lock-box 2 replaces the original lock-box as the confirmation set for every comparison that involves
the raw-channel HGB; the original lock-box results are kept and labelled as non-confirmatory for it.
